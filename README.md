# NEXEM

Crie um aplicativo web inspirado no design minimalista e moderno do Medly AI para estudantes do ENEM. Use um tema escuro sofisticado (dark mode com tons de grafite escuro, quase preto, e detalhes em roxo neon ou azul elétrico). O layout deve ter uma barra lateral (sidebar) fixa na esquerda com links para: 'Dashboard', 'Simulado', 'Redação Inteligente' e 'Estatísticas'. Na tela principal, exiba um banner elegante com a frase 'Seu tutor de IA para o ENEM' e três cartões modernos mostrando o progresso de estudos semanal, a última nota simulada e um cronômetro de estudos.
